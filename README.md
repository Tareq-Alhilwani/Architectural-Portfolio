\## 🌐 Overview



This application acts as a digital archive and portfolio site, featuring a dual-language interface (English and Arabic) to showcase various design projects. It includes metadata, descriptions, image paths, and links to 3D models (`.glb` assets) for projects spanning multiple categories:

\* \*\*Architectural Design\*\* (e.g., Media Center in Damascus, Faculty of Architecture)

\* \*\*Urban Design\*\* (e.g., Syrian Embassy in Washington D.C., Tourist Village in Lattakia)

\* \*\*Urban Planning\*\* (e.g., Residential Complex Masterplan in Homs, Urban Study of Al-Midan District)

\* \*\*Executive Drawings\*\* (e.g., High-Rise Commercial Building, Sports Court Wide Steel Structure)

\## 📊 Data Structure



The application dynamically populates its interface using a central data module (`PROJECTS\_DATA`). Each project item utilizes the following properties:



| Key | Type | Description |

| :--- | :--- | :--- |

| `id` | String | Unique identifier for the project route or state. |

| `category` | String | Internal category slug used for filtering. |

| `category\_en` / `category\_ar` | String | Localized category titles for English and Arabic layouts. |

| `title\_en` / `title\_ar` | String | Localized project names. |

| `description\_en` / `description\_ar` | String | Contextual descriptions highlighting goals, sites, or scale. |

| `model` | String | Relative path to the 3D `.glb` file (empty string if unavailable). |

| `thumbnail` | String | Path to the preview cover image. |

| `images` | Array | Array of objects containing additional render URLs and localized captions. |
